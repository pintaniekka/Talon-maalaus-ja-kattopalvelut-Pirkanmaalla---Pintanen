# Yöajo 27.10.2026: loppuraportti

Ajettu pilvi-istunnossa 26.10.2026 ohjeen `docs/yoajo-ohje-pilvi-2026-10-27.md` mukaan. Kaikki seitsemän pakettia ovat
luonnos-PR:inä, yhtään ei ole yhdistetty. Jokaisen paketin lopuksi ajettiin lint (0 virhettä), testit (60), build,
`verify_dist.py` (0 ongelmaa) ja `verify_redirects.py` (431 sääntöä, 0 ongelmaa). Lomakkeita ei lähetetty, salaisuuksia ei luettu.

Huomio: pilvi-istunto ei voi muuttaa projektin asetuksia, joten ohjetiedoston sisältöä ei kopioitu "projektin ohjeeksi".
Istunto luki tiedoston ja noudatti sitä sellaisenaan.

## Yhdistämisjärjestys

1. #121 artikkelit → 2. #122 GEO → 3. #123 auditointi → 4. #124 vaihe 12 (tehty #123:n päälle; kohdehaara vaihtuu itsestään
`main`-haaraksi, kun #123 on yhdistetty) → 5. #125 uudet sivut → 6. #126 linkit → 7. #127 GBP → 8. tämä raportti (#128).
Paketit koskevat osin samoja tiedostoja (`faqData.ts`, `seo.ts`, artikkelit) mutta eri riveihin, joten ne yhdistyvät
järjestyksessä ilman käsityötä. Jos jokin ristiriita silti tulee, se on #122:n ja #126:n välillä `faqData.ts`:ssä.
